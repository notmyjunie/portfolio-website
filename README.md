# ⚡ Material Design 3 Portfolio

A modern, responsive portfolio website built with clean, semantic web standards and inspired by **Material Design 3 (M3 Expressive)** principles. Features dynamic theme toggling, custom glassmorphism components, and responsive layout architectures.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Build](https://img.shields.io/badge/status-active-brightgreen.svg)

---

## ✨ Features

- **Material Design 3 Expressive Components:** Solid surface cards, recessed focus capsules, and elevated primary buttons with custom dynamic glows.
- **Glassmorphic Navigation:** Floating, double-layered frosted glass navbar utilizing `backdrop-filter` and fallback state management for smooth rendering across all browsers.
- **Brand-Tinted Social Pills:** Interactive social buttons with platform-specific branding (GitHub, LinkedIn, WhatsApp) that feature soft idle states and full-color hover triggers.
- **Dynamic Theme Adapting:** Seamless light and dark mode toggling using Material Design surface tokens and CSS custom properties.
- **Mobile First & Responsive:** Custom flexbox layouts with touch-friendly targets, full-width chip stacking, and adaptive viewports.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure with high accessibility standards.
- **CSS3:** Native CSS variables, modern flexbox/grid layouts, `color-mix()` syntax, and custom animations.
- **JavaScript (ES6+):** Lightweight interactivity, dynamic theme state management, and clipboard interaction.
- **Hosting:** Deployed via [Vercel](https://vercel.com).
